## Teaching calendar

The term calendar is not hand-written: it is derived from the two official
calendars (ENEI and PUCP) by the scripts in [`schedule/`](schedule/), which
resolve the scheduling conflict between both programs and split the hours
between instructor and teaching assistant.

The deliverable shared with the ENEI and the teaching assistant is
[`schedule/output/horario_peu_cd_2026_ml1_ml2.xlsx`](schedule/output/horario_peu_cd_2026_ml1_ml2.xlsx).

See [`schedule/README.md`](schedule/README.md) for the rules and how to reproduce it.

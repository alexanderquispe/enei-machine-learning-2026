# Reference material

Source material the course is built from. **None of it is ours to redistribute.** This
folder exists so that the instructor and the teaching assistant work from the same files;
it is the reason the repository is private and must stay private.

PDFs and datasets here are tracked with **Git LFS** (`.gitattributes` at the repository
root). Run `git lfs install` once before cloning, otherwise these files arrive as text
pointers.

| Folder | What it is | Provenance | Terms |
|---|---|---|---|
| `caltech_cs155/lecture_notes/` | 15 lectures + 3 recitations of CS 155 *Machine Learning & Data Mining*, Winter 2026 | Prof. Yisong Yue, Caltech | Course-internal. Not for redistribution. |
| `caltech_cs155/problem_sets/` | Sets 2–6 and the Shakespeare miniproject: statements, LaTeX templates, notebooks, data | CS 155 staff, Caltech | Same |
| `caltech_cs155/problem_sets/solutions/` | The instructor's own solutions to sets 1–5, as submitted | Alexander Quispe | Personal work |
| `ml_foundations/` | *Machine Learning Foundations*, 204 slides, with full LaTeX source | Alexander Quispe | Own material; reused freely in `ml1/` |
| `deep_learning_up/` | Git submodule → [`alexanderquispe/deep-learning-up`](https://github.com/alexanderquispe/deep-learning-up): the MECA deep learning course | Alexander Quispe, Universidad del Pacífico | Own material; adapted in `ml2/` |

## What is deliberately not here

- `set4/venv/` from the CS 155 folder — 6 GB of Windows PyTorch binaries.
- Raw MNIST files (`*-ubyte`) — regenerated by `torchvision` on first use.
- LaTeX build artifacts (`.aux`, `.log`, …) from any of the sources.

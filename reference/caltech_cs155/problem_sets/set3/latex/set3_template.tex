\begin{problem}[2]
    Describe and explain the behaviour of the loss curves for gradient boosting and for AdaBoost. You should consider two kinds of behaviours: the smoothness of the curves and the final values that the curves approach.
\end{problem}
\begin{solution}
\textbf{Smoothness:} Gradient boosting produces smooth curves because each weak regressor fits continuous residuals, making incremental adjustments. AdaBoost produces step-like, jagged curves because it uses discrete 0/1 classification loss---the loss only changes when a point switches from correctly to incorrectly classified (or vice versa), causing abrupt jumps.

\textbf{Final values:} Gradient boosting exhibits strong overfitting: training loss approaches 0 while test loss plateaus around 0.26. This occurs because regressors can continuously reduce residuals on training data without improving generalization. AdaBoost shows less overfitting: training loss settles around 0.10 and test loss around 0.19. The reweighting mechanism in AdaBoost forces the model to focus on hard-to-classify points, providing implicit regularization. Additionally, the discrete nature of classification means perfect training accuracy is harder to achieve than zero regression residuals.

\end{solution}

\begin{problem}[2]
    Compare the final loss values of the two models. Which performed better on the classification dataset?
\end{problem}
\begin{solution}
Gradient boosting achieves near-zero training loss but a test loss
of approximately 0.26. AdaBoost achieves a training loss around 0.10
 and a test loss around 0.19. AdaBoost performed better on this classification dataset, 
 as its test loss is lower (0.19 vs 0.26). This is expected since AdaBoost is specifically
  designed for classification with discrete labels, while gradient boosting here uses 
  regression on a classification problem, leading to more overfitting and worse generalization.

\end{solution}

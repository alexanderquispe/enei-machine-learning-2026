\section{Introduction}

Modern language models generate text by learning statistical patterns in
sequences of tokens. In this project we focus on \emph{character-level language
modeling}, where the model predicts the next character given a sequence of
previous characters. Although characters are a very small unit of language,
character-level models are surprisingly powerful and can learn spelling,
punctuation, word formation, and even aspects of higher-level structure.

In this project you will explore three neural architectures for character-level
language modeling:

\begin{itemize}

\item \textbf{LSTM (Long Short-Term Memory).} A recurrent neural network that
processes text sequentially and maintains an internal hidden state representing
past context.

\item \textbf{Transformer.} A self-attention based architecture that allows each
token in a sequence to attend directly to earlier tokens.

\item \textbf{nanoGPT.} A lightweight implementation of a GPT-style transformer
language model that you will train and fine-tune on the Shakespeare corpus.

\end{itemize}

These models learn sequence structure in fundamentally different ways, and
comparing their behavior will help illustrate the strengths and limitations of
each architecture.

the vocabulary consists of the unique characters appearing in the dataset
(letters, punctuation, whitespace, etc.). In the provided implementation this

The dataset is first converted into a long sequence of integer token IDs
corresponding to characters. The data is then split into training and validation
sets. During training the model receives fixed-length windows of characters
and learns to predict the next character in the sequence.

Character-level modeling has several advantages for generative poetry tasks.
First, it avoids the need for a large vocabulary, which simplifies the modeling
problem. Second, it allows the model to learn spelling and punctuation patterns
directly. Finally, it naturally supports creative generation of new words and
stylistic variations.

\section{Part 1: Character-Level LSTM (20 points)}

In this section you will train a character-level LSTM model to generate
Shakespearean text.

The LSTM is a type of recurrent neural network designed to address the
vanishing gradient problem that occurs in standard RNNs. It maintains an
internal memory state and uses gating mechanisms to determine how information
should be stored, forgotten, or exposed at each step of the sequence.

The provided notebook implements a multi-layer character-level LSTM
architecture. Each character is first mapped to an embedding vector, which
is then processed through stacked LSTM layers. The final hidden state is
passed through a fully-connected layer followed by a softmax function to
produce a probability distribution over the next character.

The model is trained to minimize categorical cross-entropy loss between the
predicted character distribution and the true next character.

Your report should briefly describe the configuration you chose and explain
any hyperparameters that you experimented with.

When generating text from the model, we often modify the sampling distribution
using a \emph{temperature parameter}, denoted by $T$. Temperature controls how
random the generated text will be.

Lower values of $T$ make the model more deterministic and repetitive, while
higher values of $T$ increase randomness and diversity but may reduce
coherence.
\pagebreak

Given logits $z_i$, the temperature-scaled probability of character $i$ is

\[
P(i) = \frac{\exp(z_i/T)}{\sum_j \exp(z_j/T)}
\]

\section{Part 2: Transformer Language Model (nanoGPT) (20 points)}

In this section you will train a transformer-based language model using the
nanoGPT implementation.

Unlike recurrent networks, transformers process sequences using
\emph{self-attention}. Self-attention allows each token in a sequence to
directly attend to earlier tokens within a fixed context window.

This mechanism enables the model to capture long-range relationships between
words without relying on sequential hidden-state propagation.

The notebook provides a complete nanoGPT implementation. You are \textbf{not

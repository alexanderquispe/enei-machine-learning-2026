# Build Plan — ML I & ML II Course Repository

Execution plan for building the full course repository: slides, tutorials, labs and
reference material for **Machine Learning I** and **Machine Learning II** (PEU-CD 2026,
ENEI — INEI), to be shared with the teaching assistant.

**Everything in this repository is written in English.**

---

## 0. Course stance

This is a **Caltech-style course, not an applied-economics course.** That is a deliberate
change from the first draft of the calendar, where sessions were anchored in poverty
prediction and program targeting. Those anchors are dropped.

What replaces them:

| Principle | What it means in the slides |
|---|---|
| **Derivations are the content** | Every result is derived on the slide, line by line. No "it can be shown that". |
| **State the object before using it** | Definition, assumptions, then the theorem, then the proof. |
| **Matrix notation throughout** | $\bm X \in \mathbb{R}^{N\times p}$, gradients as vectors, Hessians as matrices. |
| **Numerical example after each derivation** | A small worked instance with actual numbers, verified in Python. |
| **Applications are illustrations, not motivation** | A dataset appears to demonstrate a method, never to justify it. |

The reference for tone and density is `ML_Foundations.pdf` (204 slides): a definition, the
algebra in full, the geometric reading, then the estimator. Example — its Normal Equations
slide states $\mathrm{RSS}(\bm\beta)=(\bm y-\bm X\bm\beta)^\top(\bm y-\bm X\bm\beta)$,
differentiates to $-2\bm X^\top(\bm y - \bm X\bm\beta)$, gives the second derivative
$2\bm X^\top\bm X$, sets the gradient to zero and solves. That level, on every slide.

## 3. Toolchain

`pdflatex` and `latexmk` are **not installed**. `tectonic` is, at
`~/.local/bin/tectonic`, and a Beamer + metropolis + amsmath document was compiled
successfully as a test before writing this plan.

```bash
tectonic ml1/lectures/lecture_01_supervised_learning/lecture_01.tex
```

Tectonic fetches packages on demand and caches them, so the first build of each new
package set is slower. `scripts/build.py` walks the tree, compiles everything, and reports
failures in a table.

One known incompatibility, already diagnosed: **`minted` does not build under tectonic**
(it shells out to Pygments). It is commented out of the shared preamble. If syntax
highlighting is ever needed beyond what `listings` gives, that is the line to revisit.

Figures are generated by Python (matplotlib) into PDF and included — no hand-drawn TikZ
where a plot is meant, and no binary figure without the script that made it. The TikZ
macros in `deep-learning-up/dl-course-tikz/` (`\weightgrid`, `\featuremap`,
`\filterblock`) are reused for network diagrams.

### 4.2 ML I — the six lectures

Each entry lists the derivations that must appear in full. This is the acceptance
criterion for the lecture: if a derivation is missing, the lecture is not done.

---

**Lecture 1 — Supervised Learning and Linear Models** · Mon Sep 7
*Sources: CS 155 Lecture 1 · ML_Foundations 4–38*

- Supervised learning setup; hypothesis class; empirical risk
- Least squares: $\mathrm{RSS}(\bm\beta)$, gradient, Hessian, normal equations
- $\hat{\bm\beta}=(\bm X^\top\bm X)^{-1}\bm X^\top\bm y$ — existence and rank deficiency
- Hat matrix $\bm H = \bm X(\bm X^\top\bm X)^{-1}\bm X^\top$; **prove** $\bm H^2=\bm H$, $\bm H^\top = \bm H$
- Geometric reading: $\hat{\bm y}$ as orthogonal projection onto $\mathrm{col}(\bm X)$
- Sampling distribution $\hat{\bm\beta}\sim\mathcal N(\bm\beta,\sigma^2(\bm X^\top\bm X)^{-1})$
- **Bias–variance decomposition, derived term by term**, including the cross-term vanishing
- Why 0/1 loss is intractable: non-convex, flat almost everywhere
- Numerical example: $N=5$, $p=2$, solve by hand and verify in `verify_math.py`

**Lecture 2 — Optimization and Linear Classifiers** · Fri Sep 11
*Sources: CS 155 Lectures 2–3 · ML_Foundations 18–32, 89–106*

- Gradient descent from the first-order Taylor expansion; steepest-descent direction
- Step size: convergence for $L$-smooth convex $f$ with $\eta \le 1/L$ — **full proof**
- SGD and mini-batch; unbiasedness of the stochastic gradient
- **Perceptron mistake bound**: with margin $\gamma$ and radius $R$, at most $R^2/\gamma^2$ mistakes — the complete two-sided argument
- Max-margin classifier as a constrained quadratic program; the KKT conditions
- Hinge loss as the convex surrogate; subgradient
- Logistic regression: likelihood, score equations $\sum_i (y_i-p_i)\bm x_i = \bm 0$
- Hessian $-\sum_i p_i(1-p_i)\bm x_i\bm x_i^\top$; **prove** it is negative semidefinite ⟹ concavity
- Newton–Raphson, then IRLS as weighted least squares $(\bm X^\top\bm W\bm X)^{-1}\bm X^\top\bm W\bm z$

**Lecture 3 — Regularization and Evaluation** · Mon Sep 14
*Sources: CS 155 Lectures 3–4 · ML_Foundations 39–87*

- Ridge: $\hat{\bm\beta}_\lambda = (\bm X^\top\bm X+\lambda\bm I)^{-1}\bm X^\top\bm y$; **prove** invertibility for $\lambda>0$
- Ridge in the SVD basis: shrinkage factor $d_j^2/(d_j^2+\lambda)$ per singular direction
- Constrained ↔ penalized equivalence via Lagrange multipliers, both directions
- Lasso: subgradient of $\|\bm\beta\|_1$; **derive the soft-thresholding operator** for the orthogonal design
- Why $\ell_1$ produces exact zeros: KKT argument plus the geometric one
- Cross-validation; the optimism of training error
- Confusion matrix, precision/recall, ROC-AUC, average precision
- Cost-sensitive loss: derive the optimal threshold from the cost matrix

**Lecture 4 — Decision Trees and Bagging** · Fri Sep 18
*Source: CS 155 Lecture 5*

- Trees as piecewise-constant functions on axis-aligned partitions
- Impurity: misclassification, Gini, entropy; **prove** Gini and entropy are concave and why that matters
- Information gain: derive $\Delta = H(S) - \sum_k \frac{|S_k|}{|S|}H(S_k) \ge 0$ from concavity
- Bernoulli variance as impurity; regression trees and squared-error splits
- Greedy top-down training; note the NP-hardness of the optimal tree
- Stopping rules as regularizers; cost-complexity pruning
- Bootstrap; **derive** $\mathrm{Var}\big(\tfrac1B\sum_b h_b\big) = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2$ and read off why decorrelation is what random forests buy

**Lecture 5 — Boosting** · Mon Sep 21
*Source: CS 155 Lecture 6*

- Weak learnability; the boosting question
- Function space; **functional gradient descent** — the derivation that makes gradient boosting a gradient method
- Gradient boosting algorithm, with the line search for the step
- AdaBoost: **derive $\alpha_t = \tfrac12\ln\frac{1-\varepsilon_t}{\varepsilon_t}$** by minimizing exponential loss at each round
- **Training-error bound** $\prod_t 2\sqrt{\varepsilon_t(1-\varepsilon_t)}$ and the exponential-decay corollary
- Why AdaBoost keeps improving test error past zero training error: the margin explanation
- XGBoost's second-order objective, briefly, as the modern form

**Lecture 6 — Unsupervised Learning: Clustering and PCA** · Mon Sep 28
*Sources: CS 155 Lecture 9 · deep-learning-up Lecture 6 (linear algebra half)*

- $k$-means objective; assignment and update steps as coordinate descent
- **Prove** the objective decreases monotonically and the algorithm terminates
- Agglomerative clustering and linkage criteria
- PCA: maximize $\bm u^\top\bm\Sigma\bm u$ subject to $\|\bm u\|=1$ → Lagrangian → **eigenvector equation**
- **Prove** the equivalence between maximum variance and minimum reconstruction error
- SVD; relation between eigenvalues of $\bm X^\top\bm X$ and singular values of $\bm X$
- Eckart–Young: the best rank-$k$ approximation, stated and proved for the Frobenius norm
- Eigenfaces as the worked example

## 5. Review pass

Nothing is pushed before this passes. Three scripts, each with a hard failure condition.

### 5.1 `scripts/build.py` — everything compiles

Compiles every `.tex` with tectonic, prints a table of results.
**Fails on:** any compile error; any unresolved reference (`??` in the PDF); any
`Overfull \hbox` above 20 pt.

### 5.2 `scripts/check_slides.py` — no defects a reader would see

Extracts the text of every generated PDF and fails on:

- **Placeholder titles.** `ML_Foundations.pdf` ships two slides titled literally
  "Frame Title" (pages 119–120). That is the exact defect this check exists to prevent.
- **Empty frames.** Same deck, page 11: a slide with a heading and no body.
- Leftover `TODO`, `FIXME`, `\textcolor{red}` or Lorem text.
- Slide budget: a 3-hour session is 45–65 slides at this density. Flags anything outside.
- Every figure referenced from the text actually exists.

### 5.3 `scripts/verify_math.py` — the numbers are right

**Every numerical example in every deck is recomputed in Python** — numpy for the algebra,
sympy for the symbolic steps — and compared against the number printed on the slide.
Each example carries a tagged comment in the `.tex` linking it to its check.

This is the check that matters most. A wrong sign in a hand-worked gradient is invisible in
a compile pass and obvious to a room of statisticians.

Covered: the Lecture 1 least-squares example, the Lecture 2 perceptron trace and IRLS step,
the Lecture 3 soft-thresholding values, the Lecture 4 information-gain computation, the
Lecture 5 AdaBoost weights over three rounds, the Lecture 6 PCA eigenvalues, and every
worked example inherited from `deep-learning-up`.

### 5.4 Manual read

A full read of each deck against its source, checking that no derivation step was dropped
in transcription and that notation is consistent across all twelve lectures — the same
symbol for the design matrix everywhere, one convention for gradient orientation.
